# Sri Vigneshwara Agencies — B2B Wholesale Beverage Distribution Store

A modern, high-performance mobile-first B2B e-commerce platform built for **Sri Vigneshwara Agencies**, a premier wholesale distributor of soft drinks, packaged drinking water, fruit juices, and soda mixers based in Visakhapatnam, Andhra Pradesh, India.

---

## 📱 Mobile-First Commerce UI (Inspired by Reference)

The user interface matches the professional B2B wholesale app layout:

1. **Top Header Bar**:
   - Hamburger navigation menu
   - Official **Sri Vigneshwara Agencies** brand logo
   - Quick action shortcuts: `LOGIN` badge, Rewards, Wholesale Deals, and Cart with live count badge.
   - **Interactive Location Bar**: `📍 P7X4+WJR, Kalinganagar, Madhavadhara, Visakhapatnam, AP 530007` with location route checker.
   - **Prominent Rounded Search Bar**: Real-time filtering with red lens and voice-search trigger.

2. **Hero Promotional Banner Carousel**:
   - Styled after high-energy trade banners with **"UPTO 35% OFF"** starburst badge.
   - Commercial beverage imagery with carousel slide indicators.

3. **Trending Categories Grid**:
   - 3-column mobile / 6-column desktop rounded card grid:
     - Soft Drinks (55% Margins)
     - Packaged Drinking Water (Daily Bulk)
     - 20L Bulk Jars (Office & Event Refill)
     - Fruit Juices (Pulp Mango)
     - Soda & Mixers (High Fizz Club Soda)
     - Cans & Energy Drinks (Tray Packs)

4. **B2B Trade Supply Chain Partner Banner**:
   - Dedicated wholesale terms callout for retail stores, supermarkets, hotels, and caterers.

5. **Category Stores**:
   - Pastel category tiles with the signature **"View All Categories"** open-box card.

6. **24 Hrs Delivery Alert Bar**:
   - Charcoal banner highlighting 24h delivery for pincode `530007` with red **UPDATE** button.

7. **B2B Quotation Cart Engine (`QuoteCartDrawer`)**:
   - Itemized wholesale cart allowing multi-product crate orders.
   - Instant conversion: generates an itemized requisition directly to WhatsApp.

8. **Floating Deal Banner**:
   - Bottom overlay showcasing daily route deals (Bisleri 20L jars) with quick **VIEW** trigger.

9. **Sticky App Bottom Navigation**:
   - `Login` | `24h Delivery` | **Center Search** | `Orders` | `My Cart` (with badge).

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router, Static Pre-Rendering)
- **Language**: TypeScript 5.6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Brand Identity**: Sri Vigneshwara Agencies

---

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Production build
npm run build
npm run start
```
- Public Storefront: `http://localhost:3000`
- Admin Portal: `http://localhost:3000/admin` (Passcode: `admin123`)
